# 正修科大機車停車隨手記 (CSU Parking Helper)

為正修科技大學（CSU）師生量身打造的輕量化、極簡風格手機車位記錄工具 (PWA)。無需下載 App、無需註冊帳號，開啟網頁即可 3 秒快速記錄停放位置與照片！

---

## 線上實測網址

正修機車停車隨手記：https://jiaming051024.github.io/-/

手機端建議用法：
* iOS (Safari)：開啟網頁 -> 點擊底部「分享」圖示 -> 選擇「新增至主畫面」。
* Android (Chrome)：開啟網頁 -> 點擊右上角選單 -> 選擇「新增至主畫面」。

新增後即可像原生 App 一樣隨點隨用，全螢幕無網址列干擾！

## 核心特色與亮點

* 極簡黑白灰 (Monochrome Minimalist) UI：去除雜亂配色，採用高對比度暗色調設計，夜間尋車不刺眼。
* 一鍵選取與自訂車位：內建正修科大熱門停車區域（正門行政大樓、後門宿舍 A/B/C 區、體育館、圖資 B1/B2 等），亦支援自訂格位與柱號。
* GPS 定位自動抓取：支援擷取實時地理座標（經緯度與誤差範圍），戶外停車不怕迷路。
* 相機拍照備忘與圖片壓縮：免連伺服器，拍照後自動在前端進行高清壓縮並儲存於手機 LocalStorage，不佔用多餘記憶體。
* 實時停放計時器：自動計算停放總時數（小時/分/秒），方便結算停車時間。
* 一鍵地圖導航：點擊按鈕直接喚起 Apple Maps 或 Google Maps 行人導航回到車位。
* 100% 隱私安全 (Zero Backend)：所有紀錄與照片僅保存在使用者手機的 LocalStorage 中，不經過任何第三方伺服器，資料絕不外洩。
* 零套件相依 (Rock-Solid)：全內建原生 SVG 圖示與離線架構，載入速度極快，零外部庫斷連風險。

## 技術架構 (Tech Stack)

* 前端語法：HTML5 / JavaScript (ES6+) - 單頁應用 (SPA) 架構
* UI 框架：Tailwind CSS (v3 CDN) - 響應式移動端優先 (Mobile-First) 排版
* 視覺圖示：Native Inline SVG - 零外部 dependencies，保證 100% 穩定載入
* 數據儲存：HTML5 Web Storage API - 離線 LocalStorage 數據持久化
* 部署平台：GitHub Pages (HTTPS) - 免費高可用性託管，支援安全 GPS 定位權限

## 功能預覽與操作流程

[ 開啟 App ]
     |
     +-- 1. 點擊「一鍵紀錄車位」 / 快捷熱門區域
     |      +-- 選擇停車場區塊 (正門/後門宿舍棚...)
     |      +-- 輸入樓層與柱號 (例如: B1, C-12)
     |      +-- 擷取 GPS 經緯度 (選填)
     |      +-- 拍攝車位備忘照片 (選填)
     |
     +-- 2. 首頁即時顯示停放卡片 + 實時計時器
     |      +-- 顯示柱號與詳細備註
     |      +-- 點擊照片可放大全螢幕預覽
     |      +-- 點擊導航自動喚起 Google / Apple 地圖
     |
     +-- 3. 離場點擊「離場 / 結束停車」
            +-- 自動歸檔至「歷史紀錄」專區
